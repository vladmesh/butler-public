# Butler — дизайн-решения (гриллинг 2026-08-13)

Внешний агент-дворецкий над секретарём: не часть пайплайна, позже вольётся в продукт.
Все развилки закрыты владельцем (vladmesh).

1. **Мозг** — цепочка claude → codex по live-probe (паттерн `heads.toml` /
   `health.resolve_head` секретаря). Гермес отвергнут: OpenRouter — это не подписка,
   плюс зафиксированный факт куратора (2026-07-04) — не доводит протокол до конца.
2. **Процесс** — тонкий вечный мост (systemd, aiogram) + спавн головы на каждое
   сообщение с resume (`claude -p --resume` / `codex exec resume`). TUI не тащим:
   прошлые exec-баги кодекса были вызваны Orca, здесь Orca нет; владелец сознательно
   не хочет заглядывать в сессии.
3. **Голосовухи** — транскрипция Groq free tier (whisper-large-v3-turbo, 2000 req/день
   бесплатно), фоллбек OpenRouter (ключ уже есть). Локальную модель на CPU не гоняем —
   CPU уже занят эмбеддингами памяти.
4. **Телега** — обычный бот (BotFather) + жёсткий allowlist по id владельца.
   Не юзербот: риски аккаунта не окупаются.
5. **Репо** — отдельный приватный `butler`, свой systemd-юнит `Restart=always`,
   полностью вне `secretary reconcile`. Сломанный секретарь не трогает моста.
6. **Память** — memory-mcp на чтение; продиктованное владельцем («запомни») — прямой
   `secretary memory commit`; собственные выводы — `propose` в лоток куратора.
   Single-editor сохраняется: куратор вправе переписать что угодно.
7. **SSH** — реюз ключей юзера `dev` + `~/.ssh/config` с алиасами (site, codegen).
   Выделенный ключ дворецкого — позже: на одной машине с пайплайном изоляция иллюзорна.
8. **Скиллы** — свои в репо + симлинки продуктовых (`open-sprint`, `spec-card`,
   `knowledge-doc`). Скиллы работают в headless (проверено по докам Claude Code).
9. **Долгие джобы** — detached-запуск, хэндлы `state/jobs/active/*.json`; проактивные
   пинки и мониторы — этап 2, формат хэндлов закладывается сразу.
10. **Деструктивное** — мягкий протокол в персоне: необратимое/наружу → переспросить
    одним сообщением; остальное молча. Enforcement не строим — убьёт универсальность.
11. **Модели** — дефолт opus medium (claude) / terra high (codex); эскалация на
    fable medium или sol medium при сложных задачах или по прямому запросу владельца.
12. **Имя** — butler.

Известный компромисс: butler пьёт из тех же подписок, что и пайплайн — активное
общение отъедает лимит воркеров. Probe-механика обрабатывает красный ресурс штатно.
